# Security Policy

## Supported Versions

This is an active-learning project. Security fixes are applied on the latest `main` branch.

## Reporting a Vulnerability

- Do not open public issues for security vulnerabilities.
- Report privately via GitHub Security Advisories (if enabled) or direct contact with the repository owner.
- Include steps to reproduce, impact assessment, and any proof-of-concept details.

## Security Notes

- Never commit credentials, API keys, or user-sensitive data.
- Keep dependencies updated (`dependabot` is configured).
- Prefer running services behind authenticated boundaries in production deployments.
